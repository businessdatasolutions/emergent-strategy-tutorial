# Van Klassieke naar Organische Strategie

Een interactieve tutorial voor HBO Bedrijfskunde studenten over het verschil tussen klassieke (geplande) strategie en organische (emergente) strategie.

## Doel

Deze tutorial introduceert studenten op een toegankelijke en visuele manier in het concept van **emergente strategie** — hoe organisaties in de praktijk niet alleen via vooraf geplande strategieën opereren, maar ook via zich geleidelijk vormende, organische patronen. Het leermateriaal sluit aan bij het curriculum van HBO Bedrijfskunde.

## Functies

- **Interactieve Tutorial**: Stap-voor-stap doorloop van de kernconcepten via een gepagineerde interface met navigatieknoppen.
- **Visuele Presentatie**: Aantrekkelijke, donkere lay-out met duidelijke tekstblokken en visuele elementen die het leerproces ondersteunen.
- **Vergelijkend Leren**: De tutorial vergelijkt klassieke (Porter, Ansoff) met organische strategiebenaderingen (Mintzberg, complex adaptive systems).
- **Praktijkgerichte Opbouw**: Gebruik van herkenbare bedrijfsvoorbeelden om theorie te verbinden met de praktijk.
- **Enkelvoudige HTML-pagina**: Geen installatie vereist, direct te gebruiken in de browser of via GitHub Pages.

## Doelgroep

HBO Bedrijfskunde studenten die de theorie rondom strategisch management verdiepen, met name in modules over strategie, organisatieontwikkeling en verandermanagement.
